## Run Locally
1. Clone: `git clone https://github.com/Lokeshkumardulla/Tavel-Management-System.git`
2. Locate the application directory containing `manage.py`.
3. Create a virtual environment: `python -m venv .venv`
4. Activate it (PowerShell: `.venv\\Scripts\\Activate.ps1`; macOS/Linux: `source .venv/bin/activate`).
5. If the project includes `requirements.txt`, install it: `pip install -r requirements.txt`.
6. From the directory containing `manage.py`, run `python manage.py migrate` and then `python manage.py runserver`.
7. Open `http://127.0.0.1:8000/`.

> Confirm the actual project directory and dependency file in your local checkout before running these commands.
